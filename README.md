# Tape FFmpeg builds

LGPL FFmpeg 8.1.3 binaries shipped with Tape Desktop (no GPL, no non-free components).

- macOS arm64 / x64: built with `build-ffmpeg-macos-lgpl.sh` from https://ffmpeg.org/releases/ffmpeg-8.1.3.tar.xz and LAME 3.100.
- Windows / Linux: mirror of BtbN/FFmpeg-Builds `autobuild-2026-10-16-13-04` (lgpl variant); source and build scripts at https://github.com/BtbN/FFmpeg-Builds.

FFmpeg is licensed under the LGPL (https://ffmpeg.org/legal.html); each archive includes the license texts.
